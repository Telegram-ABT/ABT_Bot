# Telegram Meme Bot

Telegram бот для создания мемов и генерации изображений с помощью Midjourney API. Позволяет добавлять текст на изображения с настройкой шрифтов и цветов, а также генерировать новые изображения по текстовому описанию.

## Возможности

- Создание мемов с кастомизацией текста:
  - 10 популярных шрифтов на выбор
  - 10 цветов для текста
  - Поддержка кириллицы
- Генерация изображений через Midjourney API
- Удобное взаимодействие через inline-клавиатуру

## Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd memo
```

2. Установите зависимости с помощью Poetry:
```bash
poetry install
```

3. Создайте файл .env на основе .env.example:
```bash
cp .env.example .env
```

4. Заполните .env своими значениями:
- Получите токен для Telegram бота у @BotFather
- Получите API ключ Midjourney
- Настройте остальные параметры при необходимости

## Запуск

```bash
poetry run python memo_bot.py
```

## Использование

1. Отправьте боту изображение для создания мема
2. Используйте inline-клавиатуру для выбора шрифта и цвета
3. Добавьте текст к изображению
4. Для генерации нового изображения используйте команду /generate с описанием

## Команды

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/generate` - Сгенерировать изображение по описанию

## Переменные окружения

См. файл `.env.example` для списка всех доступных настроек.

## Требования

- Python 3.8+
- Poetry для управления зависимостями
- Доступ к Telegram Bot API
- Доступ к Midjourney API
